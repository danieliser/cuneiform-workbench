## Limits

- The static rules cover the forms listed above. Dynamic dispatch, `getattr`/`setattr`, `exec`, mutation through other objects, and code outside `cuneiform/*.py` are not modelled. When an unsupported form appears, the code should be rewritten, not the analyzer extended without bound.
- A consistent same-owner rewrite of Parquet, manifest, ledger and atlas pin passes. This is shown by a mutation case. The ledger is not a signature.
- `accepted_by` cites `reviews/atlas-recheck-v0.1.md` and the corpus reviews. They are committed with this change, unchanged, so a fresh clone passes. `--git-ref` still overlays working-tree `reviews/*.md`.
- With the atlas at `63f4221`, `--self-test --git-ref d6049e2` (or `94af111`) fails its baseline case. That is correct: the atlas no longer describes that code.
- One mutation case ("DONE block whose only hex token is a task ID") picked the first `TODO` block after Q-019. After this queue update no such block is left. It now picks the first `TODO` block with no backticked commit. A first attempt picked Q-009, which cites `d6049e2`; that block passes by design, because the rule accepts any ancestor commit token in the block.

| B1 | **Fixed** | `digest_origin()` replaces `computed()`. A `manifest_sha256` value that is an attribute, a subscript or a `.get(...)` is a copy.
