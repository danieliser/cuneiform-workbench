## Behaviour changes for consumers

- **UI:** store reads should use `resolve_snapshot`/`store_path`, or `verified(path, ledger='require')`. `PublicationError.state` can now also be `symlinked-entry`, `misplaced` or `not-found`. `auto` reads of a plain path in a store are ledger-checked even through symlinks. A path outside a store that resolves into one is labelled with that store's ledger state, not `standalone`.
- **CLI:** `--store {snapshots,cohorts}` on `publication-status|recover|adopt|repair-ledger|clean-stage`. `publication-status` adds `store`, `symlinked_entries` and per-row `id` (snapshot rows keep `snapshot`; cohort output uses `cohorts`/`cohort`). `corpus-audit` JSON adds `publication`. `corpus-select` output is unchanged.
- **Cohorts in the real store:** `derived/cohorts` has no ledger or lock today, so the three existing cohorts read as `unledgered-pre-ledger-cohort-store`. **Building any new cohort there creates the cohort ledger, and from then on these three are refused until adopted.** Adopting them is the owner's explicit decision. I did not do it.
- **Atlas drift** (for the atlas owner; I did not edit atlas files): baseline `94af111` → this commit. The `concept:rights-ledger` `rights_sources.ebl-cohort` statement hash changes from `84c9938a…` to `7e724f40577196aa4c479fcb4935478a99d8e094b4c6e92e33fb6d3d02b814bd`. The only change in the fingerprinted text is the binding of `cohort` in `storage.import_cohort`: `verify_cohort(cohort_dir,parent_path)` → `verify_cohort(cohort_dir,parent_path,ledger=cohort_ledger)` (new parameter `cohort_ledger`). The rights expression `cohort.get('rights') or RIGHTS['ebl']` and every literal are unchanged, so no grant is widened. Contract surface: `verify_cohort` gains `ledger=` and returns a `publication` key. New CLI flag `--store`. New `PublicationError` states. `storage.StoreEntry`, `publication.locate_entry`/`build_lock`/`missing_entry`. Test-only env `CUNEIFORM_TEST_PAUSE_AT`. No schema, manifest key, adapter, projection, identity or rights-text change.

## Limits

The same as the protocol: cooperating writers on one host. Same-owner OS access and root are not prevented. Symlink checks are time-of-read checks. The pre-ledger cohort store stays unledgered by design until the owner adopts its cohorts.
