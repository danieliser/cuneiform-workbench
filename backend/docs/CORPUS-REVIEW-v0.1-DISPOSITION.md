## Behaviour changes for consumers

- **UI:** `storage.verify(path, key)` now raises `PublicationError` (a `ValueError`, carrying `.state`) for unledgered, uncommitted, abandoned, conflicting or mismatched directories in the store. `storage.verified()` returns the publication label, so the UI's own ledger parsing can be replaced by it. The UI must understand ledger format-2 lines (`event` key; one ID has a `reserve` and a `commit` line). Treating "more than one line per ID" as a mismatch is now wrong. `lookup_snapshot` may raise `ScopeMismatch`/`LayerUnavailable`. Show `timing.end_to_end_ms` as the call latency, not `latency_ms`. Expect the new snapshot `snapshot:5e51403b…` (ORACC `oracc-cdl-2`, same zip receipt and texts as `snapshot:edaab55c…`). Its `input_identity` differs from the old one, because the adapter is part of the selection record ID, so label the pair by `manifest.adapter` / `selection.json` rather than grouping them by `input_identity`. Also expect the `snapshots/.locks/` directory and possibly `.recovery/`. Neither is a snapshot.
